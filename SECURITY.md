# Security policy

## Supported versions

Security fixes are provided for the latest published SkeldForge release.

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/Marcus71-q/SkeldForge/security/advisories/new) for path traversal, unsafe deletion, archive extraction, launch, credential-handling, or other security issues. Do not open a public issue before the maintainer has had a reasonable opportunity to investigate.

Do not include API keys, account data, private logs, Among Us files or third-party mod archives. A minimal reproduction and the affected SkeldForge version are enough to begin investigating.

You should receive an initial response within seven days. If private vulnerability reporting is unavailable, open a public issue containing no exploit details and ask the maintainer for a private contact channel.
