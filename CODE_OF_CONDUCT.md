# Code of conduct

## Our standards

Be respectful, constructive, and focused on improving the project. Harassment, threats, discriminatory language, personal attacks, spam, and publishing another person's private information are not acceptable.

Disagreements about implementation are welcome when they address the work rather than the person. Maintainers may edit, hide, or remove contributions that violate these standards and may temporarily or permanently restrict participation when necessary.

## Reporting

Report conduct concerns privately to the maintainer through an appropriate private GitHub channel. Security vulnerabilities belong in [private vulnerability reporting](https://github.com/Marcus71-q/SkeldForge/security/advisories/new), not in public issues.

Project maintainers are responsible for applying these standards fairly and consistently within project spaces.
